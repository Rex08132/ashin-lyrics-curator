# 阿信詩意歌詞策展台 (Mayday Lyric Curator)

> 《一天一段阿信如詩一般的詞，直到下一場演唱會》每日貼文內容庫與智能策展工作台。

## 🌟 功能亮點
- **全庫收錄**：收錄五月天 9 張創作專輯、個人主題曲及阿信為其他歌手（蔡依林、林俊傑、梁靜茹、王力宏等）作詞之 233 首經典作品。
- **邊聽邊挑**：整合 YouTube / YouTube Music / KKBOX 一鍵跳轉試聽。
- **Threads 擬真排版**：一鍵預覽與自由編輯手機版 Threads 詩意黑底貼文卡片。
- **智能打亂 (Smart Shuffle)**：依冷卻演算法自動打散同曲金句，依序重編 Day1 ~ DayN。
- **星級評價與狀態管理**：1~3 星推薦度評等、未處理/待處理/已處理進度追蹤。

## 🚀 本地啟動
```bash
pip install -r requirements.txt
streamlit run app.py
```
